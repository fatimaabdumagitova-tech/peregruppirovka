# Перегруппировка

Интерактивная игра для начальной школы: число раскладывают по разрядам (сотни, десятки, единицы), а потом перегруппировывают — меняют сотню на 10 десятков, десяток на 10 единиц — и записывают число разными суммами.

**Играть:** https://fatimaabdumagitova-tech.github.io/peregruppirovka/

Работает в браузере на компьютере, планшете и интерактивной доске; блоки можно перетаскивать пальцем или мышью.
